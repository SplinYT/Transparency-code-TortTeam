# Описание данных и правил

Источник: авторский синтетический набор prototype/demo.csv. Все обозначения вымышлены. 40 закупок, 4 заказчика, 16 поставщиков, 4 категории. Публикации 01.10.2026, окончания 03.10.2026 или 15.10.2026. Пропусков нет. Данные созданы для проверки сценария, не скачаны из ЕИС. Права третьих лиц и реальные персональные сведения не используются. Обновление ручное.

CSV: UTF-8 (допустим BOM), разделитель — запятая, десятичный знак — точка. Все поля обязательны.

| Поле | Содержание | Проверка |
|---|---|---|
| id | Уникальный идентификатор контракта | Непустой, без повторов |
| buyer | Условный заказчик | Непустая строка |
| supplier | Условный поставщик | Непустая строка |
| category | Категория | Непустая строка |
| published | Дата публикации | YYYY-MM-DD |
| deadline | Окончание подачи | Не раньше публикации |
| initial_price | Начальная цена в рублях | Конечное число >0 |
| contract_price | Цена контракта в рублях | От 0 до начальной цены |
| bidders | Число участников | Целое число ≥1 |

Снижение цены = (initial_price − contract_price) / initial_price × 100%.
Срок = deadline − published в календарных днях, без поправки на время суток.
Доля поставщика = число его контрактов / число всех контрактов заказчика в текущем наборе. Категории и периоды при группировке не разделяются.

| Код | Условие | Балл |
|---|---|---|
| R1 | bidders = 1 | 30 |
| R2 | Снижение цены <1% | 20 |
| R3 | Срок ≤3 дней | 20 |
| R4 | Доля поставщика ≥60%, у заказчика ≥5 контрактов | 30 |

Балл — сумма сработавших правил, от 0 до 100. При ≥50 закупка получает приоритет проверки. Эти пороги и веса выбраны для демонстрации, не обучены и не откалиброваны на реальных данных. Это не нормы закона и не вероятность коррупции.

Ожидаемый результат демонабора: 40 записей, 24 приоритетных. Для Z001: 100 баллов. У каждого заказчика основной поставщик имеет 7 контрактов из 10. При загрузке части набора результаты R4 могут измениться. Идентичность поставщика определяется точным совпадением строки, без нормализации ИНН и названий.
